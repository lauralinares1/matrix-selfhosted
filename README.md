## Why self-host your messaging?

We live in an era of geopolitical conflict, digital surveillance and dependence on a handful of tech giants. Matrix changes that. It is an open, federated protocol — like email, but for instant messaging — where **you own your data, your keys, and your server**.

The French military, the German government and the European Commission all run Matrix for this exact reason.

## What this deploys

Four Docker containers working as a unit:

```
          Internet (browser / mobile app)
                        │
                        ▼
             ┌─ Cloudflare Tunnel ─┐
             │  no open ports      │
             └──────────┬──────────┘
                        │
                        ▼
               ┌── Traefik :443 ──┐
               │  reverse proxy   │
               └──┬───────────┬───┘
                  │           │
                  ▼           ▼
           Synapse :8008  Element Web :80
           Matrix server  Web client (nginx)
                  │
                  ▼
            PostgreSQL
           (internal network)
                  │
                 Tor
          (v3 hidden service)
```

---

## Containers

| Container | Image | Role |
|---|---|---|
| `matrix-synapse` | `matrixdotorg/synapse` | Matrix server — manages users, rooms, messages and crypto keys |
| `matrix-element` | `vectorim/element-web` | React web client served by Nginx |
| `matrix-postgres` | `postgres:16-alpine` | Database. Initialized with locale `C` and encoding `UTF8` |
| `matrix-tor` | `osminogin/tor-simple` | v3 hidden service — censorship-resistant `.onion` access |

## Stack

<p>
  <img src="https://skillicons.dev/icons?i=docker,nginx,postgres,cloudflare,linux" />

| Layer | Technology | Why |
|---|---|---|
| Protocol | Matrix / Synapse | Open, federated, E2EE |
| Database | PostgreSQL 16 | Required for production — SQLite is testing only |
| Web client | Element Web | Official Matrix client, works in any browser |
| Proxy | Traefik | Auto-discovers containers via Docker labels, handles TLS |
| Tunnel | Cloudflare Tunnel | Public access without opening ports or exposing your IP |
| Privacy layer | Tor v3 | Alternative access path, no DNS, no IP exposure |

```
matrix/
├── .env                         # Secrets — never commit this

├── synapse/

│   ├── yourdomain.com.signing.key

```

## Quick start

```bash
# 1. Clone and enter
git clone https://github.com/youruser/matrix-selfhosted
cd matrix-selfhosted

# 2. Create secrets
cp .env.example .env
nano .env   # set POSTGRES_PASSWORD and REGISTRATION_SECRET

# 3. Generate Synapse config
docker run -it --rm \
  --mount type=bind,src=$(pwd)/synapse,dst=/data \
  -e SYNAPSE_SERVER_NAME=matrix.yourdomain.com \
  -e SYNAPSE_REPORT_STATS=yes \
  matrixdotorg/synapse:latest generate

# 4. Set permissions
sudo chown -R 991:991 synapse/
sudo chown -R 100:100 tor/hidden_service && chmod 700 tor/hidden_service

# 5. Change all domains to your own domain in all files
# Look in all files! You must change it in almost everywhere

# 6. Start
docker compose up -d
docker compose logs -f
```

## Troubleshooting

| Error | Cause | Fix |
|---|---|---|
| `Permission denied` on `hidden_service/` | Folder owned by your Linux user (UID 1000), Tor needs UID 100 | `sudo chown -R 100:100 tor/hidden_service` |
| `LC_COLLATE: en_US.utf8` | PostgreSQL cluster initialized without `POSTGRES_INITDB_ARGS` | Delete `postgres/` folder, add args to compose, restart |
| Synapse starts but Traefik shows 404 | Wrong network in label or `homelab_net` does not exist | Check `traefik.docker.network` label and `docker network ls` |
